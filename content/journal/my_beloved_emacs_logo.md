If you were ever interested in installing Emacs on macOS, you technically have three up-to-date choices[^1] ("distributions" in a very loose term) to choose from:

1. the regular Emacs install from `brew install emacs`, which is the one that the GNU foundation recommends you to install
2. [`emacs-plus`](https://github.com/d12frosted/homebrew-emacs-plus), which has additional features from "vanilla" macOS emacs 
3. [`emacs-mac`](https://github.com/railwaycat/homebrew-emacsmacport/), which adds some features that make Emacs behave more like a native app
